# Виджет «Следующий урок» (Android)

Виджет показывает: что идёт сейчас, когда звонок на перемену / на урок (с обратным отсчётом),
а также следующий урок, кабинет и время. Меняется сам ровно в моменты звонков.

## Как это работает
- Вы вводите **расписание звонков** (номер → начало/конец) и **уроки на каждый день**. Номер урока = номер строки.
- Виджет берёт текущий день недели и время, находит урок по звонкам и показывает следующий.
- «Окно» = пустая строка. Выходные и конец дня → показывается первый урок следующего учебного дня.
- Обновление идёт по будильнику на каждый звонок, а не раз в минуту — батарея не страдает.
- Всё меняется в приложении в любой момент (кнопка «Сохранить» или просто выйти — виджет обновится).

## Как получить APK без Android Studio (через GitHub)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузите в него всё содержимое этой папки (Add file → Upload files, включая папку `.github`).
3. Откройте вкладку **Actions** → «Build APK» → дождитесь зелёной галочки (2–4 минуты).
4. Внутри запуска скачайте артефакт **LessonWidget-apk**, распакуйте, перенесите `app-debug.apk` на телефон и установите
   (разрешите установку из неизвестных источников).

## Через Android Studio
Откройте папку как проект → Build → Build APK(s). Или подключите телефон и нажмите Run.

## Добавление виджета
Долгое нажатие на рабочем столе → Виджеты → «Расписание» → «Следующий урок».
Нажатие на виджет открывает редактор.

## Если виджет не обновляется вовремя
На некоторых оболочках (Xiaomi, Huawei, Samsung) нужно разрешить приложению работу в фоне:
Настройки → Приложения → Расписание → Батарея → «Без ограничений», и включить автозапуск.
